## Projeto Social de Apoio Psicopedagógico desenvolvido como Trabalho de Conclusão de Curso (TCC) para o curso Técnico em Informática do Instituto Federal da Paraíba (IFPB).

O Incluir+ é uma plataforma digital criada para otimizar e humanizar o trabalho de psicopedagogas. O sistema foca em organizar o suporte a alunos com necessidades educacionais especiais, conectando-os a uma rede de apoiadores e facilitando a documentação clínica e pedagógica. Impacto Social
Muitas vezes, o acompanhamento de alunos com necessidades especiais sofre com a fragmentação de informações. Este projeto centraliza dados cruciais, permitindo que o foco do profissional seja o que realmente importa: o desenvolvimento do aluno.

## Funcionalidades principais

    Gestão de Apoiadores: Cadastro e listagem de voluntários e profissionais de apoio.

    Gestão de Alunos (Apoiados): Controle detalhado de matrículas, turmas e perfis individuais.

    Relatórios Psicopedagógicos: Módulo para preenchimento de documentos técnicos (Identificação, Motivos, Procedimentos e Resultados).

    Sistema de Busca: Filtro inteligente em tempo real para busca rápida de perfis.
